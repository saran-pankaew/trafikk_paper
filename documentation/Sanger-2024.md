# Reproducing the Sanger-2024 Analysis

This document describes the steps used to reproduce the TRAFIKK analysis for the **Sanger-2024** drug-screen dataset.

The workflow assumes that the repository dependencies have already been installed and that the Sanger-2024 preprocessing notebook has been run as described in the main [`README.md`](../README.md).

Run all commands below from the root of the `trafikk_paper` repository unless otherwise specified.

---

## Workflow

The Sanger-2024 analysis follows the six TRAFIKK stages:

```text
01 Celios
    ↓
02 Drexpa
    ↓
03 Gitsbe
    ↓
04 Oris
    ↓
05 Synco
    ↓
06 Siflex
```

The configuration files for this dataset are located in:

```text
config/Sanger-2024/
```

Results are organized under:

```text
results/Sanger-2024/
```

Cell-line-specific files used across Celios, Drexpa, Gitsbe, and Oris are stored under:

```text
results/Sanger-2024/run_folders/
```

---

## 01. Celios

Celios integrates the omics data with the Boolean network and prepares the cell-line-specific model inputs.

Run:

```bash
celios run --config config/Sanger-2024/celios.yaml --verbose
```

The main outputs are written to:

```text
results/Sanger-2024/01_celios/
```

Cell-line-specific files required by later stages are also generated under:

```text
results/Sanger-2024/run_folders/
```

### Prepare the node dictionary for Drexpa

Drexpa requires the node dictionary generated by Celios.

Copy:

```text
results/Sanger-2024/01_celios/node_HGNC_dict.csv
```

to:

```text
data/nodes/
```

before running Drexpa.

For additional information about Celios parameters and outputs, refer to the Celios documentation.

---

## 02. Drexpa

Drexpa maps the drugs in the experimental screen to network nodes and generates the drug and perturbation information required by subsequent TRAFIKK stages.

The configuration used for the Sanger-2024 analysis is:

```text
config/Sanger-2024/drexpa.json
```

Before running Drexpa, verify the configured output directories.

Cell-line-specific files should be written into the existing:

```text
results/Sanger-2024/run_folders/
```

structure.

General Drexpa outputs should be written to:

```text
results/Sanger-2024/02_drexpa/
```

Run:

```bash
drexpa --config config/Sanger-2024/drexpa.json
```

Drexpa adds the required cell-line-specific perturbation information to the `run_folders` structure and stores its general outputs in `02_drexpa`.

For additional information about drug-target mapping, input formats, and configuration options, refer to the Drexpa documentation.

---

## 03. Gitsbe

Gitsbe generates the Boolean model ensembles used by the downstream TRAFIKK analyses.

The cell-line-specific input folders are located under:

```text
results/Sanger-2024/run_folders/
```

with the general organization:

```text
run_folders/
└── tissue/
    └── CELL_LINE/
```

Previous TRAFIKK steps already populate part of these directories. Additional files must be prepared before running Gitsbe.

### Optional: inspect the network

An optional SIF inspection script is provided:

```bash
python results/Sanger-2024/03_gitsbe/sif_inspector.py
```

The script reports network characteristics that may influence Gitsbe or Oris execution, including:

* loops
* nodes with conflicting rules
* nodes with high in-degree
* total nodes and edges
* input nodes
* output nodes

This information can also help when selecting the model output nodes.

### Model output nodes

The Gitsbe `modeloutputs` file is user-defined and was prepared manually for this analysis.

The SIF inspection results can be used to support the selection of these nodes.

### Complete the Gitsbe input folders

Run:

```bash
python results/Sanger-2024/03_gitsbe/gitsbe_set_folders.py
```

This script copies the remaining files (gitsbe config, network sif file, modeloutputs, and drugpanel file) required to run the Gitsbe JAR into each cell-line directory.

After this step, the `run_folders` contain the complete Gitsbe inputs for each cell line.

### Run Gitsbe locally

Gitsbe can be run locally using the provided helper script:

```bash
python results/Sanger-2024/03_gitsbe/run_gitsbe_local.py
```

Model generation is computationally expensive, so local execution is mainly useful for testing or small runs (1-2 cell lines).

### Run Gitsbe on HPC

For the complete analysis, HPC execution with SLURM is recommended.

Submit the provided SLURM script:

```bash
sbatch run_gitsbe.slurm
```

When preparing the HPC working directory, make sure it contains:

* the prepared `run_folders`
* the Gitsbe `.jar` file
* the required SLURM script

The generated Gitsbe results remain inside the corresponding cell-line folders and provide the model ensembles required by Oris.

For further information about Gitsbe model generation and configuration, refer to the Gitsbe documentation.

---

## 04. Oris

Oris uses the generated Boolean model ensembles and drug perturbations to calculate the downstream synergy and signal-propagation results.

For the Sanger-2024 analysis, Oris is run on an HPC system using SLURM.

The relevant outputs are stored under:

```text
results/Sanger-2024/04_oris/
```

These results are subsequently used by both Synco and Siflex.

> **Note:** The exact HPC preparation and Oris execution steps used for the paper analysis will be added to this document once finalized.

For Oris installation, configuration, execution modes, and HPC requirements, refer to the Oris documentation.

---

## 05. Synco

Synco benchmarks the computational synergy predictions generated by Oris against the experimental Sanger-2024 drug-screen results.

The scripts and helper files used for this stage are located under:

```text
results/Sanger-2024/05_synco/
```

### Prepare the experimental synergy data

The Synco experimental input:

```text
synergy_PD.csv
```

is generated using:

```text
scripts/synco_results_S2024.ipynb
```

Before running Synco, execute only the notebook cells responsible for preparing the Synco input data.

The remaining cells are used after Synco execution to analyze and summarize the results.

### Inhibitor profiles

The Synco input:

```text
inhibitor_profiles.csv
```

is user-defined and was prepared manually for the paper analysis.

### Extract the required Oris results

The Oris outputs must first be unzipped to extract the files required by Synco.

Run:

```bash
python results/Sanger-2024/05_synco/extract_oris_results.py
```

This script loops over the tissue directories and prepares the required Oris result files.

### Run Synco across tissues

A helper script is provided to run Synco sequentially across the tissue directories:

```bash
python results/Sanger-2024/05_synco/synco_run_loop.py
```

This avoids manually editing the Synco configuration and calling the synco module for every tissue.

The general Synco configuration acts as a template. During execution, the required paths and tissue/cell-line information are adapted for each run.

The main user-defined Synco parameters for this analysis are located under the:

```text
compare
```

section of the configuration file.

For additional information about these parameters and the available benchmarking options, refer to the Synco documentation.

### Process the Synco results

After all Synco runs have completed, continue with:

```text
scripts/synco_results_S2024.ipynb
```

The remaining notebook cells are used to:

* explore the benchmarking results
* calculate and inspect summary metrics
* generate visualizations
* save processed results into tables

---

## 06. Siflex

Siflex is used to explore the network- and pathway-level mechanisms associated with the predicted drug synergies.

Run:

```bash
siflex config/Sanger-2024/siflex.json
```

This performs the Siflex calculations and opens two Dash applications for interactive exploration of the results.

### Reopen previously calculated results

If the Siflex calculations have already been completed, the dashboards can be reopened without recalculating the results:

```bash
siflex config/Sanger-2024/siflex.json --no-calculate
```

This reduces the initialization time when returning to an existing analysis.

### Process the Siflex results

After the Siflex results have been generated, run:

```text
scripts/siflex_results_summary.ipynb
```

This notebook is used to:

* explore the generated results
* filter specific cases
* summarize selected analyses
* save processed results into tables

For additional information about Siflex calculations, pathway analysis, and the interactive applications, refer to the Siflex documentation.

---

## Analysis completion

After completing the six TRAFIKK stages, the main Sanger-2024 outputs are organized under:

```text
results/Sanger-2024/
├── 01_celios/
├── 02_drexpa/
├── 03_gitsbe/
├── 04_oris/
├── 05_synco/
├── 06_siflex/
└── run_folders/
```

The result-processing notebooks under `scripts/` are used to generate the summarized tables and visualizations derived from these outputs.
